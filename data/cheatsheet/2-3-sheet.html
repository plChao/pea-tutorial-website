2-3 運算元(operator)

這頁把 2-3 這個大章節的重點濃縮成一張複習表，每個小節後面都有連結可以直接跳回原章節複習細節。 ## 算術運算 | 運算子 | 意義 | 範例 → 結果 | |:---:|:---|:---| | `+` `-` `*` | 加減乘 | `3 * 2` → `6` | | `/` | 除法，**結果一定是 `float`** | `6 / 2` → `3.0` | | `//` | 整數除法(取商，捨去小數) | `7 // 2` → `3` | | `%` | 取餘數 | `7 % 2` → `1` | | `**` | 次方 | `3 ** 2` → `9` | - 優先順序：`**` > `*` `/` `//` `%` > `+` `-`，同順位由左往右，`()` 可以改變順序。 - `int` 和 `float` 混合運算，結果自動變 `float`。 - `n % 2 == 0` 是判斷偶數的常見寫法。 → [進入章節：算術運算(arithmetic operation)](lesson.html?course=001&doc=2-3-1) ## 邏輯運算 - 比較運算子(結果是 `bool`)：`==` 等於、`!=` 不等於、`>` `<` `>=` `<=`。 - **`==` 是比較，`=` 是賦值**，兩個完全不同，別搞混。 - 邏輯運算子：`and`(兩邊都成立才 `True`)、`or`(有一邊成立就 `True`)、`not`(反過來)。 - 比較/邏輯運算的結果就是 `True`/`False` 本身，可以直接 `print()` 出來看。 
print(score >= 60 and score <= 100)
→ [進入章節：邏輯運算(logical operation)](lesson.html?course=001&doc=2-3-2) ## 位元運算(1)：&、|、^ - 電腦內部用二進位表示數字，`bin(n)` 可以看 `n` 的二進位字串(開頭 `0b`)。 - `&`(AND)：兩位都 1 才是 1。`|`(OR)：有一位是 1 就是 1。`^`(XOR)：兩位不同才是 1。 
print(5 & 6)   # 4
print(5 | 6)   # 7
print(5 ^ 6)   # 3
→ [進入章節：位元運算(bitwise operation)(1)](lesson.html?course=001&doc=2-3-3a) ## 位元運算(2)：<<、>>、~ - `<<` 左移、`>>` 右移：左移 n 位等於乘 `2 ** n`，右移 n 位等於整數除以 `2 ** n`(即 `//`)。 - `~x` 永遠等於 `-x - 1`(Python 用二補數表示負數)。 - 小應用：`n & 1` 等於 `n % 2`，常用來判斷奇偶。 
print(3 << 2)   # 12
print(12 >> 2)  # 3
print(~5)       # -6
print(7 & 1)    # 1，奇數
→ [進入章節：位元運算(bitwise operation)(2)](lesson.html?course=001&doc=2-3-3b)
