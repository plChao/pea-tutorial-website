2-1 資料型別與輸入輸出(IO)

這頁把 2-1 這個大章節的重點濃縮成一張複習表，每個小節後面都有連結可以直接跳回原章節複習細節。 ## 輸出 print() - `print("文字")` 印出字串；`print(100)` 印出數字，數字不用加引號。 - 引號裡放的是**字串(string)**，單引號 `'` 雙引號 `"` 效果一樣，但同一個字串前後要一致。 - 空的 `print()` 印出一個空白行。 - 跳脫字元：`\n` 換行、`\t` 跳格、`\"` 印雙引號本身、`\\` 印反斜線本身。 - `print(a, b, c)` 一次印多個值，中間預設補一個空白。 - `sep="X"` 改變值中間的分隔符號；`end="X"` 改變結尾符號(預設是換行)。 
print("Hello", "World", sep="/", end="!\n")
→ [進入章節：輸出(output)(1)](lesson.html?course=001&doc=2-1-1a) ／ [輸出(output)(2)](lesson.html?course=001&doc=2-1-1b) ## 輸入 input() - `input()` 會暫停程式，等使用者打字按 Enter，讀到的內容要用 `變數 = input()` 存起來才能用。 - `input("提示文字")` 可以先顯示提示文字再讀輸入。 - 一個 `input()` 只讀**一行**，要讀好幾筆資料就要呼叫好幾次。 → [進入章節：輸入(input)](lesson.html?course=001&doc=2-1-2) ## 變數與資料型別 - 變數命名：只能用英文字母/數字/底線、不能數字開頭、大小寫視為不同變數、不能用關鍵字。 - 四種基本型別：`int`(整數)、`float`(浮點數)、`str`(字串)、`bool`(`True`/`False`，開頭大寫)。 - `type(x)` 檢查型別；`18` 是 `int`，`"18"` 是 `str`。 - **`input()` 讀到的永遠是 `str`**，就算輸入的是數字也一樣。 - 型別轉換：`int(x)`、`float(x)`、`str(x)`。常見寫法 `age = int(input())`，先讀再馬上轉型。 
age = int(input("請輸入你的年齡："))
→ [進入章節：變數與資料型別](lesson.html?course=001&doc=2-1-3) ## 串列 list - 建立：`nums = [10, 20, 30]`，空串列是 `[]`，元素不用同型別。 - 索引從 **0** 開始；負索引 `-1` 是最後一個。 - `len(串列)` 取長度。 - 切片 `串列[起點:終點]`：含起點不含終點；`[::-1]` 反轉整個串列。 - `in` 檢查值是否存在，結果是 `True`/`False`。 - 常用方法：`.append(x)` 加到最後、`.insert(i, x)` 插入、`.remove(x)` 刪除第一個等於 x 的元素、`.pop()` 取出並刪除最後一個。 - `.split()` 把一行文字依空白拆成串列(拆出來的每一項還是 `str`)。 
parts = input().split()   # "3 4 5" -> ['3', '4', '5']
→ [進入章節：串列(list)](lesson.html?course=001&doc=2-1-4) ## 字典 dict - 建立：`{"小明": 85, "小華": 92}`，用 `key: value` 儲存，空字典是 `{}`。 - 用 `dict[key]` 取值；key 不存在會出現 `KeyError`。 - `dict[key] = value`：key 存在就改、不存在就新增。 - `del dict[key]` 刪除一筆；`in` 檢查的是 **key** 存不存在，不是 value。 - `len(dict)` 筆數；`.get(key, 預設值)` 安全取值，key 不存在不會出錯。 - list 是「用位置查」，dict 是「用 key 查」，兩者互補。 → [進入章節：字典(dict)](lesson.html?course=001&doc=2-1-5) ## 可變與不可變 mutable / immutable - `id(x)` 看物件的記憶體位置；`a is b` 檢查兩者是不是**同一個物件**(不是比較值)。 - **不可變**：`str`/`int`/`float`/`bool`。`a = "world"` 是讓 `a` 指向一個全新物件，不會動到原本的資料，所以 `b = a` 之後改 `a` 完全不影響 `b`。 - **可變**：`list`/`dict`。`b = a` 只是讓兩個名字指向**同一份**資料，改 `b` 就等於改 `a`！ - 想要真正複製一份獨立的串列：用 `a[:]` 或 `list(a)`(字典用 `dict(d)`)。 
b = a       # 可變物件：b、a 是同一份資料
c = a[:]    # 想要獨立複製，要這樣寫
