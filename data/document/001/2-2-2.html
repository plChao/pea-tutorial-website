CHAPTER 2-2-2

邏輯運算(logical operation)

寫程式常常要「判斷」：這個數是不是比較大？兩個條件是不是同時成立？這一章介紹 Python 用來表示「對或錯」的工具。 ## 布林值：`True` 和 `False` Python 有一種專門表示「對／錯」的型態，叫做布林值(bool)，只有兩個可能的值：`True`(真) 和 `False`(假)。 ## 比較運算子 比較兩個值的大小，結果會是 `True` 或 `False`： | 符號 | 意義 | 範例 | 結果 | |---|---|---|---| | `==` | 等於 | `3 == 3` | `True` | | `!=` | 不等於 | `3 != 2` | `True` | | `<` | 小於 | `3 < 2` | `False` | | `>` | 大於 | `3 > 2` | `True` | | `<=` | 小於等於 | `3 <= 3` | `True` | | `>=` | 大於等於 | `3 >= 4` | `False` | **注意**：判斷「等於」要用兩個等號 `==`，一個等號 `=` 是「賦值」(把值存進變數)，兩者意思完全不同，這是初學最容易搞混的地方。 ## 邏輯運算子：`and`、`or`、`not` 當你需要「同時符合好幾個條件」，就要用邏輯運算子把多個 `True`/`False` 組合起來： | 運算子 | 意義 | 範例 | |---|---|---| | `and` | 兩邊都是 True，結果才是 True | `(3 > 1) and (5 > 2)` → `True` | | `or` | 其中一邊是 True，結果就是 True | `(3 > 1) or (1 > 5)` → `True` | | `not` | 把 True/False 反過來 | `not (3 > 1)` → `False` | 
age = 20
print(age >= 18 and age < 65)
輸出 `True`，因為 `age >= 18` 和 `age < 65` 兩個條件都成立。 準備好了嗎？下面的練習會用到比較運算子跟 `and`／`or`，先熟悉它們，下一章馬上就會用在 `if` 判斷式裡。
