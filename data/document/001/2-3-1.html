CHAPTER 2-3-1

算術運算(arithmetic operation)

之前你已經會用 `print()` 印出東西、用 `input()` 讀輸入、也知道變數跟 `int`/`float`/`str`/`bool` 這四種型別了。這一章要來學怎麼對數字做「運算」——也就是加減乘除這些數學操作。 ## 基本算術運算子 Python 提供的算術運算子如下： | 運算子 | 意義 | 範例 | 結果 | |:---:|:---|:---|:---:| | `+` | 加法 | `3 + 2` | `5` | | `-` | 減法 | `3 - 2` | `1` | | `*` | 乘法 | `3 * 2` | `6` | | `/` | 除法 | `3 / 2` | `1.5` | | `//` | 整數除法(取商) | `3 // 2` | `1` | | `%` | 取餘數 | `3 % 2` | `1` | | `**` | 次方 | `3 ** 2` | `9` | 
a = 7
b = 2
print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
輸出： 
9
5
14
3.5
3
1
49
## `/` 跟 `//` 的差別 這是初學者最容易搞混的地方： - `/` 是「一般除法」，**結果一定是 `float`**，就算除得盡也一樣。例如 `6 / 2` 會得到 `3.0`，不是 `3`。 - `//` 是「整數除法」，只留下商、無條件捨去小數部分，結果是 `int`(除非其中一個運算元是 `float`)。例如 `7 // 2` 是 `3`。 - `%` 是「取餘數」，`7 % 2` 是 `1`(因為 7 除以 2 商 3 餘 1)。 `//` 和 `%` 這兩個運算子在 APCS 考題裡出現頻率很高，常常用來判斷奇偶數(`n % 2 == 0` 代表偶數，這個式子怎麼用會在下一章講)、或是把一個數字拆成十位、個位等等。 ## 運算的優先順序 跟數學課學的規則一樣，Python 也有運算優先順序：`**` 最高，接著是 `*`、`/`、`//`、`%`(這幾個同一順位)，最後是 `+`、`-`。同順位的運算子由左往右算。想要改變順序，就用小括號 `()` 把想先算的部分框起來： 
print(2 + 3 * 4)
print((2 + 3) * 4)
輸出： 
14
20
`int` 和 `float` 混合運算時，結果會自動變成 `float`(例如 `3 + 0.5` 是 `3.5`)。

小知識：`+` 和 `*` 不只能用在數字上。兩個字串相加(`+`)會把它們接在一起，字串乘上一個整數(`*`)則會把字串重複那麼多次，例如 `"ab" * 3` 會得到 `"ababab"`。這在之後處理文字輸出時偶爾會用到。
