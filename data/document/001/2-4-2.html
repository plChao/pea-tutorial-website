CHAPTER 2-4-2

串列(list)

之前每個變數只能存一個值，例如 `score = 85`。但如果要存「全班 40 個人的分數」，難道要開 40 個變數 `score1, score2, ..., score40` 嗎？當然不用——Python 提供了**串列(list)**，可以用一個變數存一整排的資料。 ## 建立串列 用中括號 `[ ]` 把資料包起來，中間用逗號分隔： 
nums = [10, 20, 30, 40, 50]
names = ["小明", "小華", "小美"]
print(nums)
print(names)
輸出： 
[10, 20, 30, 40, 50]
['小明', '小華', '小美']
串列裡的元素不用同一種型別，甚至可以放另一個串列(這個之後會用在二維陣列)。空串列寫成 `[]`。 ## 索引(index)：取出某個位置的元素 每個元素都有一個位置編號，叫**索引**，**從 0 開始算**： 
nums = [10, 20, 30, 40, 50]
print(nums[0])   # 10，第一個元素
print(nums[2])   # 30，第三個元素
Python 還支援**負索引**，`-1` 代表最後一個元素，`-2` 是倒數第二個，以此類推，不用先算出串列長度： 
print(nums[-1])   # 50
print(nums[-2])   # 40
如果索引超出範圍(例如串列只有 5 個元素，卻取 `nums[10]`)，程式會直接出錯(`IndexError`)。 ## len()：串列的長度 
nums = [10, 20, 30, 40, 50]
print(len(nums))   # 5
`len()` 也適用於字串，例如 `len("hello")` 是 5。有了 `len()`，`nums[len(nums) - 1]` 就等於 `nums[-1]`(不過通常直接用 `-1` 更方便)。 ## 切片(slice)：一次取出一段 `串列[起點:終點]` 可以取出一段連續的元素，**包含起點、不包含終點**： 
nums = [10, 20, 30, 40, 50]
print(nums[1:3])    # [20, 30]
print(nums[:2])      # [10, 20]，省略起點代表從頭開始
print(nums[3:])      # [40, 50]，省略終點代表到最後
print(nums[:])       # [10, 20, 30, 40, 50]，整個複製一份
print(nums[::-1])    # [50, 40, 30, 20, 10]，反過來排
`[::-1]` 的第三個數字是「間隔」，`-1` 代表反向、每次退一格，是把串列反過來的常用寫法；字串也可以這樣切，`"hello"[::-1]` 會得到 `"olleh"`。 ## in：檢查有沒有出現 用 `in` 可以檢查某個值是否存在串列裡，結果是 `True`/`False`： 
nums = [10, 20, 30]
print(20 in nums)   # True
print(99 in nums)   # False

if 20 in nums:
    print("找到了")
## 修改串列的內容 串列建立之後**還可以修改**(這點跟數字、字串不一樣)： 
nums = [10, 20, 30]
nums[0] = 999          # 直接改某個位置的值
print(nums)             # [999, 20, 30]

nums.append(40)          # 加到最後面
print(nums)              # [999, 20, 30, 40]

nums.insert(1, 15)       # 在索引 1 的位置插入 15
print(nums)              # [999, 15, 20, 30, 40]

nums.remove(20)           # 刪除「值是 20」的第一個元素
print(nums)                # [999, 15, 30, 40]

last = nums.pop()          # 拿掉並回傳最後一個元素
print(last, nums)           # 40 [999, 15, 30]
## split()：把一行文字拆成串列 `input()` 一次只能讀一整行文字。如果一行裡有好幾個用空白隔開的資料(例如 `"3 4 5"`)，可以用字串的 `.split()` 方法拆成一個串列： 
line = input()          # 假設輸入是 "3 4 5"
parts = line.split()     # ['3', '4', '5']，注意還是字串
a = int(parts[0])
b = int(parts[1])
c = int(parts[2])
print(a + b + c)          # 12
`.split()` 拆出來的每一項都還是**字串**，如果要當數字運算，別忘了用 `int()`/`float()` 轉換。 準備好了嗎？下面的練習會用到 `[ ]`、索引、切片、`len()`、`in` 和 `.split()`。
