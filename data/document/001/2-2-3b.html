位元運算(bitwise operation)(2)

上一章介紹了 `&`、`|`、`^`、`~`，這一章接著介紹「位移」運算，也就是把所有位元整體往左或往右移動幾格。 ## 位移運算子：`<<`、`>>` | 符號 | 意義 | 範例 | 結果 | |---|---|---|---| | `<<` | 左移 n 位 | `1 << 3` | `8` | | `>>` | 右移 n 位 | `8 >> 3` | `1` | 左移一位，相當於**乘以 2**；右移一位，相當於**除以 2(無條件捨去小數)**。移動 n 位就相當於乘／除 2 的 n 次方： 
print(1 << 3)   # 1 * 2*2*2 = 8
print(20 >> 2)  # 20 // (2*2) = 5
## 常見應用：檢查某一位是不是 1 `&` 搭配左移，可以檢查一個數字「第 k 位」(從右邊數，從 0 開始)是不是 1，這在 APCS 的位元操作題型很常出現： 
n = 13          # 二進位 1101
k = 2
bit = (n >> k) & 1
print(bit)
原理：先把 `n` 右移 `k` 位，讓想檢查的那一位移到最右邊，再用 `& 1` 只留下最右邊那一位——結果不是 0 就是 1。 
print(bin(13), (13 >> 2) & 1)
`13` 是 `1101`，右移 2 位變成 `11`，`& 1` 之後得到 `1`，代表第 2 位確實是 1。這一招之後在處理「開關狀態」「集合」等題目時會很有用。
