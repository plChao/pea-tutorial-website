算術運算(arithmetic operation)

Python 的數學運算跟你在數學課學的差不多，但有幾個符號跟習慣不太一樣，這一章一次整理清楚。 ## 基本運算子 | 符號 | 意義 | 範例 | 結果 | |---|---|---|---| | `+` | 加法 | `3 + 2` | `5` | | `-` | 減法 | `3 - 2` | `1` | | `*` | 乘法 | `3 * 2` | `6` | | `/` | 除法(浮點數) | `7 / 2` | `3.5` | | `//` | 整除(無條件捨去) | `7 // 2` | `3` | | `%` | 取餘數 | `7 % 2` | `1` | | `**` | 次方 | `2 ** 3` | `8` | 其中 `//` 和 `%` 在 APCS 題目裡非常常用：`//` 可以拿到「除完之後不看小數點」的結果，`%` 可以拿到「除完剩下多少」。例如判斷一個數是不是偶數，常用 `n % 2 == 0`。 ## `/` 一定回傳浮點數 要特別注意：`/` 就算兩數剛好整除，結果也一定是浮點數(小數)： 
print(6 / 2)
輸出是 `3.0`，不是 `3`。如果想要整數結果，要用 `//`： 
print(6 // 2)
輸出才會是 `3`。 ## 運算的優先順序 跟數學一樣，`*` `/` `//` `%` 的優先順序比 `+` `-` 高，`**` 又比它們更高。不確定的話，直接加括號 `()` 最保險，也比較好讀： 
print(2 + 3 * 4)
輸出是 `14`，因為先算 `3 * 4` 再加 `2`；如果想先算加法，要自己加括號：`(2 + 3) * 4` 才會是 `20`。
